# Collection title pages

The collection images are unmodified published scans, checked visually on 2026-09-19 and 2026-09-20. The source for each image is recorded below. The pictured books are named under each image. CSS crops the images for the card; the source files retain the complete page and its existing digitization marks.

- Reformed: Daniel Chamier, *Panstratia Catholica*, vol. 1, Frankfurt, 1627. `/v1/works/chamier-panstratia-catholica-vol-1/p/2.webp`.
- Roman Catholic: Robert Bellarmine, *Disputationes de Controversiis*, vol. 1, Venice, 1621. `/v1/works/bellarmine-disputationes-de-controversiis-vol-1/p/7.webp`.
- Lutheran: Johann Gerhard, *Confessio Catholica*, book 1, Jena, 1634. `/v1/works/gerhard-confessio-catholica-liber-1/p/6.webp`.

Source host: `https://mo-tfr-library.mo-podcast-feed.workers.dev`.

Eastern Fathers: the title page of *Patrologia Orientalis*, volume 1, Paris: Firmin-Didot, 1907. Public scan from PIMS / University of Toronto via Internet Archive: https://archive.org/details/patrologiaorient01pari/page/n8/mode/1up. The printed date and title were checked visually. The complete, unmodified page is stored as `assets/images/tfr/po-title-1907.jpg`; CSS frames it on the card. This replaces the text-only placeholder and does not reuse the modern licensed PO corpus scans.

Latin Library: Francisco Suárez, *Opera Omnia*, volume 1, Paris: Louis Vivès, 1856. The library metadata identifies scan page 10 as the title page, verified visually. Source: `https://mo-tfr-library.mo-podcast-feed.workers.dev/v1/works/suarez-opera-vol-1/p/10.webp`. Stored without visual alteration as `assets/images/tfr/suarez-title.webp`, replacing the marked Alsted image.
